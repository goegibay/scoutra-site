# Scoutra Design System

Code 是唯一真值：`tokens/tokens.css` ＋ `styles.css`。
方向：克制的企業 SaaS——白＋冷灰、深靛藍 primary、1px 邊框、極少陰影、
卡片 14px／控制項 8px、Space Grotesk（display）＋ Inter（body）。
禁止：glassmorphism、裝飾性大漸層、發光、AI 味制式三欄卡。
每個資料元件必備 loading / empty / error / populated 四態。
表格每列必附 evidence 欄（產品差異化）。
`patterns/` 的 Hero A/B 是待使用者二選一的方向稿。
